# Code of Conduct

SentinelForge is a community of defenders, students, and engineers. We want participation to be respectful
and harassment-free for everyone, whatever their experience, background, or identity.

## Expected behaviour

- Be respectful and constructive. Critique ideas and code, not people.
- Assume good intent, and ask before assuming.
- Be patient with newcomers. Everyone started somewhere.
- Credit other people's work, including rules, research, and code, and respect their licenses.
- Handle security information responsibly (see [SECURITY.md](SECURITY.md)).

## Unacceptable behaviour

- Harassment, insults, discriminatory language or imagery, and personal attacks.
- Publishing other people's private information.
- Sharing real victim data, credentials, or live malicious infrastructure in issues or PRs.
- Using the project or its spaces to plan or promote attacks against systems you are not authorized to test.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently ban participants who
violate this code. Report concerns privately to the maintainers, using the contact in the repository profile or
a private security advisory. Reports are handled confidentially.

This code applies in all project spaces (issues, pull requests, discussions) and wherever someone represents the
project publicly.
